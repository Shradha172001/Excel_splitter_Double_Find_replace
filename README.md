📌 How to Check for Duplicates (Highlight)
    Select the column
    Home → Conditional Formatting
    Highlight Cells Rules → Duplicate Values
    Excel highlights repeated items

📌 How to Remove Duplicates (Steps)
    Select your data
    Go to Data → Remove Duplicates
    Choose columns to check
    Click OK
    Excel keeps the first entry and removes the rest

📌 Text to Columns (Split Data)
    Select the column
    Data → Text to Columns
    Choose Delimited (comma, space, etc.)
    Finish
    (Shortcut path: Alt → A → E)

📌 Flash Fill
    Type the pattern in one cell
    Press Ctrl + E
    Excel fills the rest automatically

📌Find & Replace
    Find → Ctrl + F
    Replace → Ctrl + H
